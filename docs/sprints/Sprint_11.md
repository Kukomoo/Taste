# Sprint 11 - Extraction, Cluster Detail, Backend Boundary, Extension Wrapper

## Goal

Work through the next product-hardening list in order after command palette:

1. Manual real screen-recording permission test support.
2. Real transcription pipeline boundary for audio nodes.
3. OCR/text extraction pipeline boundary for keyframes.
4. Cluster detail view for inspecting all nodes.
5. Prompt generation from frames and transcript.
6. Auth/storage backend boundary.
7. Chrome extension wrapper for tab/page capture workflows.

## Scope

- Add real-recording QA checklist.
- Add transcription, OCR, and prompt-generation modules.
- Add OCR nodes to recording clusters.
- Add cluster inspector UI.
- Add local storage provider interface as the backend seam.
- Add MV3 extension scaffold.

## Exit Criteria

- Recording output is inspectable as a full node cluster.
- Extraction work has clear module boundaries ready for real services.
- Backend and extension work have concrete starting points.
