# Sprint 4 - Research and Archive Modes

## Goal

Make sessions and archive management functional.

## Scope

- Add start and end session actions.
- Attach session captures to active project.
- Add Research timeline across projects.
- Add Archive mode compact list.
- Add archive/unarchive actions.
- Add archive cleanup suggestion and archive export.

## Tests

- Starting a session creates current session.
- Ending a session creates summary-ready ended session.
- Archive cleanup finds old unused archived captures.
- Archive export includes only archived items.

## Exit Criteria

- User can run a research session, review it later, archive items, and export archived data.
