# Sprint 3 - Inspiration Mode

## Goal

Create a visual-first Create mode with rediscovery and moodboards.

## Scope

- Add visual gallery.
- Add filters for all, project, UI, branding, illustration, and motion.
- Add random inspiration tile.
- Add selection and moodboard creation.
- Show moodboards in Create mode.

## Tests

- Inspiration selector returns visual unarchived captures.
- Filters narrow results by tag or project.
- Moodboard action creates a board from selected captures.

## Exit Criteria

- User can browse visual saves, select them, create a moodboard, and rediscover an older inspiration item.
