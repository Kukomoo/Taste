# Sprint 1 - App Foundation and Project Mode

## Goal

Create the working TASTE prototype foundation and make Project Mode useful for builders.

## Scope

- Bootstrap React + Vite + TypeScript.
- Add global mode navigation.
- Add local state and persistence.
- Seed demo projects and captures.
- Build Project Mode board.
- Add create project, switch project, save capture, pin capture, and random project memory.
- Add project digest preview.

## Tests

- App renders.
- Project selectors return active project captures.
- Save capture action attaches to active project.
- Digest ranking prefers pinned and revisited captures.

## Exit Criteria

- User can open the app, switch modes, create a project, save a capture to it, and see the capture on the board.
