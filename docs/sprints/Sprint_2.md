# Sprint 2 - Growth Mode

## Goal

Make Growth Mode visually and behaviorally distinct.

## Scope

- Add Growth Mode coaching-feed layout.
- Add weekly focus card.
- Add recently saved and never-tried sections.
- Add tried, skipped, and not relevant actions.
- Add growth curation helper.

## Tests

- Growth focus selects an untried growth capture.
- Marking an item tried updates state.
- Not relevant items are downranked or removed from focus.

## Exit Criteria

- User can open Improve mode, act on one suggested save, and see the state update.
